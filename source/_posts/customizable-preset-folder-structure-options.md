**IFolder CommonFiles64** \- Gets Common Files 64 folder.

**IFolder Windows** \- Gets Windows folder.

**IFolder WindowsVolume** \- Gets Windows Volume folder.

**IFolder System** \- Gets System folder.

**IFolder System16** \- Gets System 16 folder.

**IFolder System64** \- Gets System 64 folder.

**IFolder Fonts** \- Gets Fonts folder.

**IFolder Temporary** \- Gets Temporary folder.
